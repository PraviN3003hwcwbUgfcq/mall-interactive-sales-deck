# Setup Instructions

## 1. Clone the repository

```bash
git clone https://github.com/PraviN3003hwcwbUgfcq/mall-interactive-sales-deck.git
```

## 2. Navigate into the project

```bash
cd mall-interactive-sales-deck
```

## 3. Install dependencies

```bash
npm install
```

## 4. Run development server

```bash
npm run dev
```

## 5. Build for production

```bash
npm run build
```

# Design Decisions

The project was intentionally designed as a single-page immersive storytelling experience rather than a traditional multi-page website.

Key design goals included:

* Creating a premium luxury visual identity
* Using motion to guide user attention naturally
* Building cinematic transitions inspired by Apple, Tesla, and luxury retail presentations
* Maintaining minimal UI clutter
* Prioritizing typography, spacing, and atmosphere
* Designing responsive layouts that preserve the immersive feel across screen sizes

The visual language combines:

* Dark luxury aesthetics
* Gold accent highlights
* Large typography
* Layered gradients
* Motion-driven interactions
